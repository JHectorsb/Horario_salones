# 🏫 Horario Salones

> ⚠️ **Aplicación en proceso de desarrollo** — Esta app aún está siendo construida y puede contener errores o funciones incompletas.

Aplicación móvil desarrollada con **React Native + Expo** para consultar la disponibilidad de salones y horarios en la institución.

---

## 📱 Funciones actuales

- 📋 Consulta de salones disponibles por hora y día
- 🗓️ Visualización del horario general de salones

---

## 🚀 Funciones a futuro

Estas son las mejoras y características planeadas para próximas versiones:

### 📅 Horario Personal
Permitir a cada usuario registrar y visualizar su propio horario de clases para consultar rápidamente sus materias, salones asignados y horarios específicos.

### ✏️ Editar Salones Libres
Dar la posibilidad de marcar o actualizar el estado de un salón (libre / ocupado) directamente desde la app, manteniendo la información actualizada en tiempo real.

### 💬 Sugerencias y Comentarios
Sección dedicada para que los usuarios puedan enviar sugerencias de mejora, reportar problemas o dejar comentarios sobre el uso de la aplicación.

## ⚙️ Instalación y ejecución local

```bash
# Clonar el repositorio
git clone https://github.com/JHectorsb/Horario_salones.git
cd Horario_salones

# Instalar dependencias
npm install

# Ejecutar con Expo
npx expo start
```

---

## 📦 Build (Android)

```bash
eas build --platform android
```
